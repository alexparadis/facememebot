## 1. What the Bot does

FaceMemeBot generates joke images. A user registers a person by uploading a photo of that
person's face and adding short written statements ("facts") about them. When someone runs
`/meme` or `/versus`, the Bot sends those facts to an AI text model to compose a scene
description, then sends that description together with the stored face photo to an AI image
model, which produces a new image depicting that person in the scene. The image is posted
back to the Discord channel where the command was run.

FaceMemeBot is a free, non-commercial hobby project. It is provided as-is.
